# Backend e Node.js com JWT

## Padrao REST

    * GET /users - Listar todos os usuários
    * GET /users/:id - Listar um usuário específico
    * POST /users - Criar um novo usuário
    * PUT /users/:id - Atualizar um usuário existente
    * DELETE /users/:id - Deletar um usuário existente


No nosso caso criamos um produto,
entao temos os endpoins: 
    * GET /products - Listar todos os produtos
    * GET /products/:id - Listar um produto específico
    * POST /products - Criar um novo produto
    * PUT /products/:id - Atualizar um produto existente
    * DELETE /products/:id - Deletar um produto existente
