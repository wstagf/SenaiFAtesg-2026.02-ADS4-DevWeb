# 📋 ATIVIDADE 2: Editar o Site


**Objetivo:** Adicicionar o conteudo do seu site em tags semanticas, div, a, img, ul, ol, li, span, strong, em e hr.

### Tags da Aula 1 (obrigatórias)
```
<!DOCTYPE html>
<html>
<head>
<body>
<meta>
<title>
<h1> até <h6>
<p>
<br>
<hr>
```

### Tags da Aula 2 (obrigatórias)

```
<div>       (agrupador genérico de conteúdo)
<span>      (agrupador inline, dentro de texto)
<ul>        (lista não-ordenada)
<ol>        (lista ordenada)
<li>        (item de lista)
<img>       (imagem - opcional, apenas se quiser)
id=""       (atributo de identificação - OBRIGATÓRIO para navegação)
Tags semânticas (opcionais)
<header>    (cabeçalho do site)
<nav>       (menu de navegação)
<main>      (conteúdo principal)
<article>   (conteúdo independente)
<section>   (seção de conteúdo)
<footer>    (rodapé do site)
```


## ⚠️ O que NÃO fazer

❌ Adicionar CSS (nem mesmo `<style>` na head)  
❌ Adicionar JavaScript  
❌ Usar imagens (a menos que seja parte do conteúdo)  
❌ Pular hierarquia de títulos (h1 → h3)  
❌ Criar múltiplos `<h1>` por página  
❌ Esquecer de IDs nas seções  
❌ Links não funcionando  
❌ Código desorganizado ou sem indentação
