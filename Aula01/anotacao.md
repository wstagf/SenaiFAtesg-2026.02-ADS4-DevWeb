# Aula 01 - Dev Web - Anotação

## Termos
    * HTML - Hypertext Markup Language
    * Tags - Marcação de elementos, inciam com < e terminam com > e primeia a ser lida é a HTML, ela possui duas filhas <head> e <body>
    * Atributos - São informações adicionais que podem ser passadas para as tags, como por exemplo: <a href="https://www.google.com">Google</a>




## Informacoes uteis
    * w3c - World Wide Web Consortium, é uma comunidade internacional que desenvolve padrões para a web. O w3c é responsável por criar e manter as especificações de HTML, CSS, XML e outros padrões relacionados à web.
