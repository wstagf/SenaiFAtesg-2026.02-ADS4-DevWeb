1. Abrir o poweshell em modo administrador e rodar o comando abaixo:
$ Set-ExecutionPolicy unrestricted
    o comando vai perguntar se você deseja alterar a política de execução, digite "A" e pressione enter.

2. Escolha a pasta onde deseja criar o projeto e abra o terminal nessa pasta.

3. rodar o comando para criar o projeto com VITE( https://vite.dev/)
$ npm create vite@latest NossaPrimeiraAula


4. das proximas vezes, rode o projeto com o comando: (OBSERVAÇÃO: o comando abaixo deve ser rodado dentro da pasta do projeto)
$ npm run dev
